# Network Traffic Flow & Analysis with Wireshark

This repository contains my practical lab exercises on packet-level network analysis using Wireshark. The objective of these projects is to capture, filter, and dissect network traffic to understand protocol mechanics, connection flows, and data exfiltration techniques.

**Source Lab:** [Los-merengue/Network-Traffic-Flow-with-WireShark-for-Beginners](https://github.com/Los-merengue/Network-Traffic-Flow-with-WireShark-for-Beginners)

## 📂 Lab Projects

### [Project 1: Analyzing DNS, TCP, HTTP, and TLS Traffic](./Project-1/README.md)
A 21-task visual breakdown of foundational network protocols. This section demonstrates how to isolate domain resolution queries, track the TCP 3-way handshake, inspect plaintext HTTP payloads, and observe encrypted TLS handshakes.
